Formula — how each roll is derived
# on every new Nano block (hash H, 64-hex → 32 raw bytes)
salt   = crypto.getRandomValues(32)              # fresh CSPRNG salt, per roll
prefix = salt ++ bytes(H)                       # 64 bytes: secret anchor + public block
stream  = SHA-256( prefix ++ counter )            # counter-mode byte stream, counter = 0,1,2,…
face    = 1 + unbiased_int( [0, sides), stream )  # one face per die, rejection sampling

# unbiased_int — rejection sampling (no modulo bias)
k   = 1 if sides ≤ 256 else 2 if sides ≤ 65536 else 4
lim = 256k - (256k mod sides)
do: v = read k bytes from stream (big-endian)
while v ≥ lim                               # discard the modulo-bias zone, redraw
return v mod sides
salt = 32 raw CSPRNG bytes (secret, never sent)  ·  H = triggering Nano blockhash (public, verifiable)  ·  counter = increments each 32-byte stream block  ·  lim = largest multiple of sides ≤ 256k

This page watches the Nano network in real time. Every time a new block is confirmed, the dice roll automatically — each face is drawn uniformly via rejection sampling (no modulo bias) from a SHA-256 counter-mode stream seeded with a fresh 32-byte CSPRNG salt plus the triggering blockhash. The result depends on that fresh, public, timestamped block — it is not reproducible from any previous roll, and one broken browser RNG alone cannot collapse it.
