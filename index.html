Simple BIP39 Seed Generator — base on Nano blockchain

Entropy: —

One file, no tracking — by default entropy comes only from your browser's Web Crypto CSPRNG (the standard way wallets derive BIP39 seeds), fully offline. With "Mix live Nano blockhashes" and/or a user salt, a fresh random 32-byte salt is hashed together with your UTF-8 salt text and up to 16 validated live Nano blockhashes via SHA-256 per Generate (Salt ++ User salt ++ Blockhashes). Write the phrase down on paper and keep it offline. Anyone with these words owns the wallet.

Why mix live Nano blockhashes? Browser CSPRNG is the secret anchor, but it is a single point of failure — a buggy or mocked browser RNG alone would make your seed fully reproducible. Folding public, timestamped block windows into the hash means an attacker must also know which window your Generate drew from, not just the RNG output. It adds zero theoretical entropy, but it stops one broken RNG implementation from collapsing the seed.

Self-contained file — save this page (Ctrl/Cmd+S) and open it locally: zero dependencies, no build step, no network calls unless you enable block mixing.
